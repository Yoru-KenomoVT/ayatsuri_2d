# Security

Please report security problems privately, not in a public issue: a file
that crashes Ayatsuri2D or makes it misbehave on purpose, or anything in a
release download that should not be there.

Email [support@ayatsuri-2d.org](mailto:support@ayatsuri-2d.org) with what
you found and the steps or file that show it. We will fix it before it is
talked about, and credit you in the release notes unless you would rather
we did not.

If you are expecting a reply, check your spam folder.

Fixes go into the latest release only, so please check the problem is still
there in it first.
